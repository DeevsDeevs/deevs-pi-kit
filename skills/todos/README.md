# Todos Skill

Guidance for using the `todo_list` tool well.

Main instruction file: [`SKILL.md`](SKILL.md).

Companion extension: [`extensions/todos`](../../extensions/todos/README.md).

## Defaults

- Use for non-trivial current-session work.
- Keep 3-8 actionable items.
- Update with complete replacement writes.
- Use `blocked` with notes instead of fake progress.
- Clear when finished.
- Use chains, not todos, for durable handoff memory.
