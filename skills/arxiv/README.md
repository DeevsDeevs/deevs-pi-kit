# arXiv Skill

Agent-facing workflow for arXiv research.

Main instruction file: [`SKILL.md`](SKILL.md).

Companion extension: [`extensions/arxiv`](../../extensions/arxiv/README.md).

## Tools

```text
arxiv_search
arxiv_get
arxiv_bibtex
```

## Use for

- paper discovery
- exact arXiv ID lookup
- abstract-level triage
- BibTeX generation
- saving research leads to chains/wiki

## Do not overclaim

arXiv metadata and abstracts are research leads. They do not provide peer-review status, citation counts, or enough evidence for detailed full-paper claims.
